Acceso Rápido a URLs de Configuración de Chrome (chrome://)

Debido a políticas de seguridad del navegador, las páginas web no pueden abrir enlaces chrome:// directamente. Haz clic en cualquiera de los botones para copiar la URL al portapapeles y pegarla en una nueva pestaña.

¿Qué hacer si ves "NotAllowedError: Permission Policy is not enabled"?

Chrome restringe las Web AI APIs para que no puedan ejecutarse dentro de <iframe>s sin permiso explícito del sitio web padre.

Pasos para Activar Gemini Nano en Chrome (v148+)

  1. 1. Activar Prompt API Flag:
    Abre la URL en una nueva pestaña y cambia el flag a Enabled Multilingual. chrome://flags/#prompt-api-for-gemini-nano
    Recomendación para español: Selecciona la opción Enabled Multilingual en el desplegable.
  2. 2. Ajustes de Sistema / IA en el Dispositivo:
    Asegúrate de que la opción de IA local esté activa en la pestaña de sistema. chrome://settings/system
  3. 3. Reiniciar navegador: Haz clic en "Relaunch" tras cambiar el flag.
  4. 4. Iniciar y monitorear la descarga (~2.5 GB):
    Abre DevTools (F12) y ejecuta await LanguageModel.create(). Comprueba en chrome://components el componente Optimization Guide On Device Model.
